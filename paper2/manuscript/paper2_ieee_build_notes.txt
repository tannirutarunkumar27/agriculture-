HOW TO BUILD THE PDF ON WINDOWS (MiKTeX / TeX Live)
----------------------------------------------------
Open a Command Prompt or PowerShell in the manuscript directory:

  cd "D:\Final Project\implementation_for _crop recommendation\paper2\manuscript"

Recommended two-pass build (resolves cross-references and bibliography):

  pdflatex paper2_ieee.tex
  pdflatex paper2_ieee.tex

If you use \cite{} with the thebibliography environment (as in this file),
two pdflatex passes are sufficient. No BibTeX/Biber run is needed because
all \bibitem entries are written directly in the .tex file.

If you later switch to \bibliography{references} + \bibliographystyle{IEEEtran},
run:

  pdflatex paper2_ieee.tex
  bibtex   paper2_ieee
  pdflatex paper2_ieee.tex
  pdflatex paper2_ieee.tex

MiKTeX (Windows): install MiKTeX from https://miktex.org/download
TeX Live (Windows): install TeX Live from https://tug.org/texlive/

Both distributions include pdflatex and the IEEEtran class.
